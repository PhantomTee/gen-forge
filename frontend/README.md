# GenForge 🛠️
**The AI-Powered Smart Contract Architect for GenLayer**

GenForge is an on-chain Intelligent Contract factory. It allows users to describe their desired smart contract in natural language and utilizes GenLayer's consensus-driven LLM execution to draft verified Python contracts.
